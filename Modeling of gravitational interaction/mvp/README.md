# MVP (~50% срока лабораторной)

**Как читать код:** `common.h` → `physics_dll.c` → `main_win.c` (в каждом файле есть комментарии в начале и у ключевых блоков).

Урезанная веха проекта «Моделирование гравитационного взаимодействия»: демонстрирует **архитектуру** и **минимально работающую симуляцию**, без полировки и без части требований курса.

Полная версия — в корне репозитория (`../`).

## Что уже есть в MVP (первая половина работ)

| Компонент | Статус |
|-----------|--------|
| CMake: `gravity_physics.dll` + `gravity_sim.exe` | да |
| Разделение exe / DLL, `LoadLibraryW` + `GetProcAddress` | да |
| `VirtualAlloc` для массивов тел в DLL и буфера рендера в exe | да |
| Velocity Verlet, N тел, смягчение ε, G | да |
| Один пресет: гравитационное облако вокруг центра | да |
| Win32 окно, GDI (круги), двойная буферизация | да |
| Игровой цикл ~60 FPS, пауза, сброс сцены | да |
| Простой HUD (число тел, шаг, FPS) | да |
| Зум колёсиком, панорама ПКМ | да |

## Что планируется ко 100% (вторая половина)

## Сборка

Из CLion: открыть `mvp/CMakeLists.txt` как отдельный проект или:

```text
cmake -S mvp -B mvp/build -G "MinGW Makefiles"
cmake --build mvp/build
```

Запуск: `mvp/build/gravity_sim.exe` (рядом должна лежать `gravity_physics.dll`).

## Управление

- **Пробел** — пауза  
- **R** — пересоздать сцену  
- **ПКМ + перетаскивание** — камера  
- **Колёсико** — зум
